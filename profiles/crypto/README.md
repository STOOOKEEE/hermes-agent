# Profil `crypto`

`SOUL.md` est déployé vers `~/.hermes/profiles/crypto/SOUL.md`.

Créer séparément sur le serveur `~/.hermes/profiles/crypto/WALLETS.md`, par exemple :

```markdown
# Wallets surveillés

- ethereum — treasury — `0x...`
- xrpl — operations — `r...`
```

Ce fichier est volontairement ignoré par Git. Il doit contenir uniquement des adresses
publiques et des libellés, jamais de seed, clé privée ou keystore.
